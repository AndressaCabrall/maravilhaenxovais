# Maravilha Cortinas & Persianas

Site institucional para a **Maravilha Cortinas** — especialista em cortinas e persianas sob medida em Ibitinga/SP e região.

**Stack:** Next.js 14 · CSS Modules · Framer Motion · JavaScript  
**Hospedagem:** Hostinger (`output: export`)  
**Dev:** [Cabrals Web | Presença Digital](https://cabralsweb.com.br)

---

## Rodar o projeto

```bash
npm install
npm run dev
npm run build   # gera /out para deploy
```

---

## SEO implementado

**On-page:** Metadata completo, H1/H2/H3 otimizados, alt texts com palavras-chave locais, blog com 6 artigos 1000+ palavras por intenção de busca.

**Técnico:** Schema.org LocalBusiness + FAQPage + Service, geo tags Ibitinga/SP, sitemap.xml com todas as URLs, robots.txt liberado para bots de IA, output estático otimizado para Hostinger.

**Local:** 4 páginas de cidade dinâmicas (`[cidade]`), 6 páginas SEO por produto/serviço, canonical URL por página.

**Off-page:** Links entre sites do portfólio Cabrals Web — Regina Cortinas & Decorações (Cachoeirinha/RS), Artmari Decor (Barra Velha/SC) e D Coração Cortinas e Persianas (Itatiba/SP).

---

## Estrutura de páginas

```
/                                   → Home
/blog                               → Blog
/blog/[slug]                        → Artigos (6)
/[cidade]                           → Cidades dinâmicas (4)
/cortinas-sob-medida-ibitinga       → SEO produto
/persianas-sob-medida-ibitinga      → SEO produto
/cortina-wave-ibitinga              → SEO produto
/persiana-blackout-ibitinga         → SEO produto
/cortina-pe-direito-duplo           → SEO produto
/cortina-motorizada-ibitinga        → SEO produto
/privacidade                        → Institucional
```
